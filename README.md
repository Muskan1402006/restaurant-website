# Saffron & Sage — Restaurant Website

A responsive restaurant website built with HTML, CSS and vanilla JavaScript.

## Run in VS Code
1. Extract this folder.
2. Open `project-resturant` in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Features
- Responsive navigation for mobile and desktop
- Menu category filters
- Add-to-order cart with quantity and total
- Cart saved using browser localStorage
- Reservation form with date validation and demo confirmation

## Notes
This is a front-end college/portfolio project. The reservation form does not send data to a server, and the order cart does not process payments. Menu photography is loaded from Unsplash, so an internet connection is needed for those images.
